Login & Register Form

A clean and simple authentication page built with pure HTML, CSS and JavaScript. No frameworks, no build step: just open it and it works.

Features
Login and Register forms with a smooth sliding tab switch
Password strength meter with a live checklist (8+ characters, a letter, a number and a symbol)
Show / hide password button on every password field
Form validation with clear error messages (email format, matching passwords, required fields)
Terms checkbox required before creating an account
Social sign-up buttons for Google, Apple and GitHub (UI only, ready to be connected)
About me button that opens a box with the developer description
